# YAML 配置与 Go 代码的关联机制

## 核心问题：配置如何转化为代码？

配置文件中的一行代码：
```yaml
- authentication: primary_password
```

如何变成 Go 代码中的：
```go
return authflow.NewSubFlow(&IntentUseAuthenticatorPassword{...}), nil
```

---

## 第一步：配置解析（YAML → Go 结构体）

### 1.1 配置定义在 config 包

文件：`pkg/lib/config/authentication_flow.go`

```go
// 对应 YAML 中的: type: login, name: default_login_flow
type AuthenticationFlowLoginFlow struct {
    Name  string                           `json:"name,omitempty"`
    Steps []*AuthenticationFlowLoginFlowStep `json:"steps,omitempty"`
}

// 对应 YAML 中的: - type: identify 或 - type: authenticate
type AuthenticationFlowLoginFlowStep struct {
    Name     string                              `json:"name,omitempty"`
    Type     AuthenticationFlowLoginFlowStepType `json:"type,omitempty"`  // "identify" / "authenticate"
    Optional *bool                               `json:"optional,omitempty"`
    OneOf    []*AuthenticationFlowLoginFlowOneOf `json:"one_of,omitempty"`
    TargetStep string `json:"target_step,omitempty"`
}

// 对应 YAML 中的: - identification: email 或 - authentication: primary_password
type AuthenticationFlowLoginFlowOneOf struct {
    Identification model.AuthenticationFlowIdentification `json:"identification,omitempty"`  // "email"
    Authentication model.AuthenticationFlowAuthentication `json:"authentication,omitempty"`  // "primary_password"
    BotProtection  *AuthenticationFlowBotProtection `json:"bot_protection,omitempty"`
    Steps          []*AuthenticationFlowLoginFlowStep `json:"steps,omitempty"`
}
```

## 第二步：Intent 如何关联到配置（JSON Pointer 机制）

### 2.1 Intent 中保存的 JSONPointer

```go
// intent_login_flow_step_authenticate.go
type IntentLoginFlowStepAuthenticate struct {
    FlowReference authflow.FlowReference `json:"flow_reference,omitempty"`
    JSONPointer   jsonpointer.T          `json:"json_pointer,omitempty"`  // ← 关键字段！
    StepName      string                 `json:"step_name,omitempty"`
    UserID        string                 `json:"user_id,omitempty"`
    Options       []AuthenticateOption   `json:"options"`
}
```

**JSONPointer 示例：**

```yaml
# 配置
- name: default_login_flow
  type: login
  steps:
    - type: identify              # JSON Pointer: /steps/0
      one_of:
        - identification: email   # JSON Pointer: /steps/0/one_of/0
    - type: authenticate          # JSON Pointer: /steps/1
      one_of:
        - authentication: primary_password  # JSON Pointer: /steps/1/one_of/0
```

| Intent | JSONPointer | 对应配置位置 |
|--------|-------------|-------------|
| IntentLoginFlowStepIdentify | `/steps/0` | `steps[0]` |
| IntentUseIdentityLoginID | `/steps/0/one_of/0` | `steps[0].one_of[0]` |
| IntentLoginFlowStepAuthenticate | `/steps/1` | `steps[1]` |
| IntentUseAuthenticatorPassword | `/steps/1/one_of/0` | `steps[1].one_of[0]` |

### 2.2 如何获取配置对象

```go
// intent_login_flow_step_authenticate.go:410-420
func (i *IntentLoginFlowStepAuthenticate) currentFlowObject(
    deps *authflow.Dependencies,
    flows authflow.Flows,
    origin authflow.NodeOrIntent,
) (config.AuthenticationFlowObject, error) {
    // 1. 找到当前 Flow 对应的配置根对象（整个 login flow 配置）
    rootObject, err := findNearestFlowObjectInFlow(deps, flows, origin)

    // 2. 用 JSONPointer 在配置树中找到当前 Intent 对应的配置
    //    如：i.JSONPointer = "/steps/1"
    current, err := authflow.FlowObject(rootObject, i.JSONPointer)

    return current, nil  // 返回 *config.AuthenticationFlowLoginFlowStep
}
```

**可视化：**

```
配置树（YAML 解析后的结构）
├── name: "default_login_flow"
├── type: "login"
└── steps: [
    0: {type: "identify", one_of: [...]},    ← /steps/0
    1: {                                     ← /steps/1 (current 指向这里)
        type: "authenticate",
        one_of: [
            0: {authentication: "primary_password"},  ← /steps/1/one_of/0
            1: {authentication: "secondary_totp"}
        ]
    }
]
    │
    │ i.JSONPointer = "/steps/1"
    ▼
┌────────────────────────────────────────────────────┐
│ step := i.currentFlowObject(...)                   │
│ step.Type = "authenticate"                         │
│ step.OneOf[0].Authentication = "primary_password"  │
└────────────────────────────────────────────────────┘
```

## 第三步：ReactTo 如何使用配置

### 3.1 使用 step.Type 决定行为

```go
// intent_login_flow_steps.go:69-92
func (i *IntentLoginFlowSteps) ReactTo(...) (authflow.ReactToResult, error) {
    // 获取当前配置
    current, err := i.currentFlowObject(deps, flows, i)
    steps := current.GetSteps()  // 获取所有 steps

    // 获取当前 step 的配置
    step := steps[i.NextStepIndex].(*config.AuthenticationFlowLoginFlowStep)

    // 根据 step.Type 创建对应的 Intent
    switch step.Type {  // ← 使用配置中的 type 字段！
    case config.AuthenticationFlowLoginFlowStepTypeIdentify:
        // 配置中写的是 type: identify
        result = authflow.NewSubFlow(&IntentLoginFlowStepIdentify{...})

    case config.AuthenticationFlowLoginFlowStepTypeAuthenticate:
        // 配置中写的是 type: authenticate
        result = authflow.NewSubFlow(&IntentLoginFlowStepAuthenticate{...})

    case config.AuthenticationFlowLoginFlowStepTypeCheckAccountStatus:
        // 配置中写的是 type: check_account_status
        result = authflow.NewSubFlow(&IntentLoginFlowStepCheckAccountStatus{...})
    }

    i.NextStepIndex = i.NextStepIndex + 1
    return result, nil
}
```

### 3.2 使用 step.OneOf 生成选项

```go
// intent_login_flow_step_authenticate.go:93-111
func NewIntentLoginFlowStepAuthenticate(...) (*IntentLoginFlowStepAuthenticate, error) {
    // 1. 获取配置
    current, err := i.currentFlowObject(deps, flows, originNode)
    step := i.step(current)  // step 是 *config.AuthenticationFlowLoginFlowStep

    // 2. 根据配置和用户已有认证器生成可用选项
    //    step.OneOf 包含配置中写的所有 authentication 选项
    options, deviceTokenEnabled, err := getAuthenticationOptionsForLogin(
        ctx, deps, flows, i.UserID, step,
    )

    // options 中可能包含：
    // - primary_password (如果用户有密码认证器)
    // - secondary_totp (如果用户设置了 TOTP)
    // - primary_passkey (如果用户有 passkey)

    i.Options = options
    return i, nil
}
```

### 3.3 用户选择后映射到具体 Intent

```go
// intent_login_flow_step_authenticate.go:256-310
func (i *IntentLoginFlowStepAuthenticate) ReactTo(...) (authflow.ReactToResult, error) {
    // 1. 获取配置
    current, err := i.currentFlowObject(deps, flows, i)
    step := i.step(current)

    // 2. 获取用户选择
    var inputTakeAuthenticationMethod inputTakeAuthenticationMethod
    if authflow.AsInput(input, &inputTakeAuthenticationMethod) {
        authentication := inputTakeAuthenticationMethod.GetAuthenticationMethod()
        // authentication = "primary_password" (用户选择的值)

        // 3. 在配置中查找索引（验证用户选择是否合法）
        idx, err := i.getIndex(step, authentication)  // idx = 0

        // 4. 根据 authentication 字符串映射到具体的 Intent 类型
        switch authentication {
        case model.AuthenticationFlowAuthenticationPrimaryPassword:
            // 配置中是: authentication: primary_password
            // 创建: IntentUseAuthenticatorPassword
            return authflow.NewSubFlow(&IntentUseAuthenticatorPassword{
                JSONPointer:    authflow.JSONPointerForOneOf(i.JSONPointer, idx),
                UserID:         i.UserID,
                Authentication: authentication,
            }), nil

        case model.AuthenticationFlowAuthenticationSecondaryTOTP:
            // 配置中是: authentication: secondary_totp
            // 创建: IntentUseAuthenticatorTOTP
            return authflow.NewSubFlow(&IntentUseAuthenticatorTOTP{
                JSONPointer:    authflow.JSONPointerForOneOf(i.JSONPointer, idx),
                UserID:         i.UserID,
                Authentication: authentication,
            }), nil

        case model.AuthenticationFlowAuthenticationPrimaryOOBOTPEmail:
            // 配置中是: authentication: primary_oob_otp_email
            // 创建: IntentUseAuthenticatorOOBOTP
            return authflow.NewSubFlow(&IntentUseAuthenticatorOOBOTP{
                JSONPointer:    authflow.JSONPointerForOneOf(i.JSONPointer, idx),
                UserID:         i.UserID,
                Authentication: authentication,
            }), nil
        }
    }
}
```

| `primary_password` | `AuthenticationFlowAuthenticationPrimaryPassword` | `IntentUseAuthenticatorPassword` |
| `secondary_password` | `AuthenticationFlowAuthenticationSecondaryPassword` | `IntentUseAuthenticatorPassword` |
| `primary_passkey` | `AuthenticationFlowAuthenticationPrimaryPasskey` | `IntentUseAuthenticatorPasskey` |

func (i *IntentLoginFlowStepIdentify) ReactTo(...) (authflow.ReactToResult, error) {

## 总结：配置 → 代码的完整链路

```
YAML 配置
    │
    │ 解析 (config 包 Schema 定义)
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ config.AuthenticationFlowLoginFlow                                          │
│ └── Steps: []*config.AuthenticationFlowLoginFlowStep                        │
│     ├── [0]: {Type: "identify", OneOf: [...]}                              │
│     └── [1]: {Type: "authenticate", OneOf: [                                │
│              0: {Authentication: "primary_password"},                      │
│              1: {Authentication: "secondary_totp"}                         │
│         ]}                                                                   │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    │ Intent 通过 JSONPointer 获取配置
    │ i.JSONPointer = "/steps/1"
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ IntentLoginFlowStepAuthenticate                                             │
│ └── currentFlowObject()                                                     │
│     └── step := current.(*config.AuthenticationFlowLoginFlowStep)           │
│         └── step.Type = "authenticate"                                       │
│         └── step.OneOf[0].Authentication = "primary_password"               │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    │ ReactTo 中使用配置
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ switch step.Type {                                                          │
│ case "authenticate":                                                         │
│     // 生成选项                                                             │
│     options := getAuthenticationOptionsForLogin(step)                       │
│         │                                                                   │
│         ▼                                                                   │
│     用户选择: "primary_password"                                              │
│         │                                                                   │
│         ▼                                                                   │
│     switch authentication {                                                 │
│     case "primary_password":                                                 │
│         return authflow.NewSubFlow(&IntentUseAuthenticatorPassword{...})    │
│     }                                                                       │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    │ 创建 Node
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ Node{                                                                        │
│   Type: NodeTypeSubFlow,                                                     │
│   SubFlow: &Flow{                                                            │
│     Intent: &IntentUseAuthenticatorPassword{                                  │
│       UserID: "user123",                                                     │
│       Authentication: "primary_password",  ← 配置值保存在 Intent 中           │
│       JSONPointer: "/steps/1/one_of/0"                                        │
│     }                                                                        │
│   }                                                                          │
│ }                                                                            │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    │ appendNode
    ▼
Flow.Nodes = append(Flow.Nodes, node)
```

## 核心要点

1. **配置是树形结构**：YAML 解析成 `config.AuthenticationFlowLoginFlow` 等结构体
2. **JSON Pointer 定位**：每个 Intent 用 `JSONPointer` 字段记住自己在配置树中的路径
3. **配置驱动行为**：
   - `step.Type` 决定创建什么 Intent（identify/authenticate）
   - `step.OneOf` 生成可用选项供用户选择
   - 用户选择后，通过 `switch-case` 映射到具体的 Intent 类型
4. **Intent 保存配置值**：如 `IntentUseAuthenticatorPassword.Authentication` 保存 `"primary_password"`
