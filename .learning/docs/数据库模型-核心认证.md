note right of User
  核心用户表，包含：
  - 账户状态管理
  - 用户属性（标准/自定义）
  - 账户生命周期管理
end note

note right of Identity
  身份基表，支持多种类型：
  - Login ID (邮箱/手机/用户名)
  - OAuth (第三方登录)
  - Anonymous (匿名用户)
  - Biometric (生物识别)
  - Passkey (WebAuthn)
  - LDAP (企业目录)
  - SIWE (Web3)
end note

note right of Authenticator
  认证器基表，支持多种类型：
  - Password (密码)
  - OOB-OTP (邮箱/短信验证码)
  - TOTP (时间型OTP)
  - Passkey (WebAuthn)
end note
