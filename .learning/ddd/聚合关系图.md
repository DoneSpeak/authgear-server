  User聚合根
  - 管理Identity和Authenticator
  - 控制账户状态
  - 维护用户属性
end note

  Session聚合根
  - 管理用户会话
  - 支持SSO
  - 控制会话生命周期
end note

note right of Flow
  AuthenticationFlow聚合根
  - 管理认证流程执行
  - 声明式流程定义
  - 支持分支和条件
end note

  - 管理OAuth授权
  - 控制访问范围
  - 支持Social Login
