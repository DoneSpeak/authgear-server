# API 学习索引

本目录整理 Authgear 对外 API 的教程及与 DDD 领域模型的映射。

## 文档

- **[API教程.md](./API教程.md)** — 按官方分组整理的 API 路径、认证方式与用法索引
- **[API与DDD映射.md](./API与DDD映射.md)** — 各 API 对应的有界上下文/聚合，便于从 API 反查领域设计
- **[User-Profile接口说明.md](./User-Profile接口说明.md)** — 用户资料（User Profile）相关接口总览，以及如何读取与修改用户基本信息

## 学习路径

1. 阅读 [API教程.md](./API教程.md) 了解 API 分组与入口
2. 阅读 [API与DDD映射.md](./API与DDD映射.md) 理解 API 与领域模型的对应关系
3. 按需深入某类 API：教程内已链接到 `docs/specs` 对应 spec
