架构概览

Authgear Authentication Flow 整体架构

Authgear 采用声明式的认证流程系统，基于状态机模式设计，具有高度可配置性和扩展性。

核心架构图

graph TB A[客户端请求] --> B[Authentication Service] B --> C[Flow Manager] C --> D[Intent 处理器] D --> E[Node 执行器] E --> F[Milestone 状态管理] F --> G[Store 存储] G --> H[数据库/Redis] I[Web UI] --> B J[移动端] --> B K[第三方应用] --> B
设计理念：
  • 声明式配置：通过配置文件定义认证流程
  • 状态机驱动：基于状态机的流程控制
  • 事件驱动：通过输入事件驱动状态转换
  • 依赖注入：通过 Dependencies 注入各种服务依赖
  • 效果分离：将副作用效果与业务逻辑分离

interface Intent {

功能：实现具体的认证步骤和行为

interface Node {

功能：管理认证流程的完整状态
作用：流程状态持久化和恢复 
class Flow {
    private String flowId;

    private Intent intent;
    private List<Node> nodes;

Intent & Milestone 机制

Intent 系统设计

Intent 是认证流程的入口点，负责流程的初始化和状态转换。

IntentLoginFlow：处理登录流程的初始化和状态转换
IntentSignupFlow：处理注册流程的初始化和状态转换

Milestone 机制

Milestone 用于标记流程中的重要状态点，支持流程控制和状态查询。

主要里程碑类型： 
// 流程控制里程碑
interface MilestoneDoCreateSession extends Milestone {
    Session getSession();
}

// 数据提供里程碑
interface MilestoneDidAuthenticate extends Milestone {
    Authentication getAuthentication();
    List<String> getAMR();
}

// 约束提供里程碑
interface MilestoneConstraintsProvider extends Milestone {
    Constraints getConstraints();
}
示例：里程碑在流程中的作用

当用户完成密码认证时，系统会设置 MilestoneDidAuthenticate 里程碑，表示认证已完成。后续流程会检查这个里程碑来决定下一步的操作。

状态转换机制

流程执行循环： 
public FlowState processInput(String flowId, Input input) {
    // 1. 获取当前流程状态
    Flow flow = flowRepository.findById(flowId);
    
    // 2. 查找当前 InputReactor
    InputReactor reactor = findCurrentInputReactor(flow);
    
    // 3. 验证输入数据
    InputSchema schema = reactor.canReactTo(context);
    
    // 4. 执行 ReactTo 逻辑
    ReactToResult result = reactor.reactTo(context, input);
    
    // 5. 生成新的节点或子流程
    if (result.isSubFlow()) {
        createSubFlow(result);
    } else if (result.isNode()) {
        createNode(result);
    }
    
    // 6. 执行效果
    executeEffects(result.getEffects());
    
    return updateFlowState(flow);
}

关键节点实现

NodeAuthenticatePassword 实现： 
public class NodeAuthenticatePassword implements Node {
    @Override
    @Transactional
    public ReactToResult reactTo(AuthenticationContext context, Input input) {
        // 1. 获取用户的密码认证器
        AuthenticatorInfo info = getPasswordAuthenticator(context);
        
        // 2. 验证密码
        AuthenticatorSpec spec = new AuthenticatorSpec.Builder()
            .password(input.getPassword())
            .build();
            
        VerificationResult result = authenticatorService.verify(context, info, spec);
        
        // 3. 返回已验证的认证器节点
        if (result.isSuccess()) {
            return new ReactToResultBuilder()
                .node(new NodeVerifiedAuthenticator(info))
                .milestone(new MilestoneDidAuthenticate(info))
                .build();
        } else {
            return new ReactToResultBuilder()
                .error(new AuthenticationException("Invalid credentials"))
                .build();
        }
    }
}
NodeAuthenticationTOTP 实现： 
public class NodeAuthenticationTOTP implements Node {
    @Override
    @Transactional
    public ReactToResult reactTo(AuthenticationContext context, Input input) {
        // 1. 获取用户的 TOTP 认证器
        AuthenticatorInfo info = getTOTPAuthenticator(context);
        
        // 2. 验证 TOTP 代码
        AuthenticatorSpec spec = new AuthenticatorSpec.Builder()

            .build();

        if (result.isSuccess()) {
            return new ReactToResultBuilder()
                .node(new NodeVerifiedAuthenticator(info))
                .milestone(new MilestoneDidAuthenticate(info))
                .build();
        } else {
            return new ReactToResultBuilder()
                .error(new AuthenticationException("Invalid TOTP code"))
                .build();
        }
    }
}

配置生成机制

配置生成器： 
@Configuration
public class AuthenticationFlowConfiguration {
    
    @Bean
    public FlowConfiguration flowConfiguration(AuthenticationFlowProperties properties) {
        FlowConfiguration config = new FlowConfiguration();
        
        // 生成登录流程配置
        if (properties.getFlows().getLogin().isEnabled()) {
            config.addFlow("login", generateLoginFlow(properties));
        }
        
        // 生成注册流程配置
        if (properties.getFlows().getSignup().isEnabled()) {
            config.addFlow("signup", generateSignupFlow(properties));
        }
        
        return config;
    }
    
    private FlowConfiguration generateLoginFlow(AuthenticationFlowProperties properties) {
        FlowConfiguration config = new FlowConfiguration();
        
        // 添加识别步骤
        config.addStep(new IdentifyStep(properties.getIdentification()));
        
        // 添加认证步骤
        config.addStep(new AuthenticateStep(properties.getAuthentication()));
        
        // 添加账户检查步骤
        config.addStep(new AccountCheckStep());
        
        return config;
    }
}

核心服务实现

FlowService 实现： 
@Service
@Transactional
public class FlowService {
    
    private final FlowRepository flowRepository;
    private final SessionRepository sessionRepository;
    private final Dependencies dependencies;
    
    @Autowired
    public FlowService(FlowRepository flowRepository, 
                     SessionRepository sessionRepository,
                     Dependencies dependencies) {
        this.flowRepository = flowRepository;
        this.sessionRepository = sessionRepository;
        this.dependencies = dependencies;
    }
    
    public FlowResponse createFlow(FlowType type, String name, SessionOptions options) {
        // 创建会话
        Session session = sessionRepository.create(options);
        
        // 根据类型创建 Intent
        Intent intent = createIntent(type, name);
        
        // 创建流程
        Flow flow = new Flow(generateFlowId(), intent, session);
        flowRepository.save(flow);
        
        // 返回响应
        return new FlowResponse(
            flow.getStateToken(),
            type,
            name,
            null
        );
    }
    
    public FlowResponse feedInput(String stateToken, Input input) {
        // 获取流程
        Flow flow = flowRepository.findByStateToken(stateToken);
        
        // 获取当前 InputReactor
        InputReactor reactor = findCurrentInputReactor(flow);
        
        // 处理输入
        ReactToResult result = reactor.reactTo(flow, input);
        
        // 执行效果
        executeEffects(result.getEffects());
        
        // 更新流程状态
        updateFlow(flow, result);
        
        // 返回响应
        return new FlowResponse(
            flow.getStateToken(),
            flow.getType(),
            flow.getName(),
            result.getAction()
        );
    }
}

代码示例

完整的主密码 + TOTP 登录流程实现

LoginIntent 实现： 
@Component
public class LoginIntent implements Intent {
    
    @Override
    public String getIntentType() {
        return "login";
    }
    
    @Override
    @Transactional
    public InputSchema canReactTo(AuthenticationContext context) {
        // 检查是否已创建会话
        if (getSessionService().hasActiveSession(context)) {
            return null; // 返回 null 表示流程结束
        }
        
        // 检查是否达到创建会话里程碑
        if (hasMilestone(context, MilestoneDoCreateSession.class)) {
            return null;
        }
        
        return new LoginInputSchema();
    }
    
    @Override
    @Transactional
    public ReactToResult reactTo(AuthenticationContext context, Input input) {
        switch (context.getCurrentState().getStepIndex()) {
            case 0:
                // 第一步：预初始化
                return handlePreInitialize(context);
            case 1:
                // 第二步：主认证
                return handlePrimaryAuthentication(context, input);
            case 2:
                // 第三步：次认证
                return handleSecondaryAuthentication(context, input);
            case 3:
                // 第四步：创建会话
                return handleCreateSession(context);
            default:
                throw new IllegalStateException("Invalid state");
        }
    }
    
    private ReactToResult handlePreInitialize(AuthenticationContext context) {
        // 创建预初始化节点
        NodePreInitialize node = new NodePreInitialize();
        return new ReactToResultBuilder()
            .node(node)
            .milestone(node)
            .build();
    }
    
    private ReactToResult handlePrimaryAuthentication(AuthenticationContext context, Input input) {
        // 处理主认证逻辑
        if (input instanceof LoginPasswordInput) {
            return handlePasswordAuthentication(context, (LoginPasswordInput) input);
        } else if (input instanceof LoginTOTPInput) {
            return handleTOTPAuthentication(context, (LoginTOTPInput) input);
        }
        
        throw new IllegalArgumentException("Unsupported input type");
    }
    
    private ReactToResult handlePasswordAuthentication(AuthenticationContext context, LoginPasswordInput input) {
        // 验证密码
        AuthenticatorInfo info = getAuthenticatorService().verifyPassword(
            context.getUserId(), 
            input.getPassword()
        );
        
        if (info == null) {
            return new ReactToResultBuilder()
                .error(new AuthenticationException("Invalid password"))
                .build();
        }
        
        return new ReactToResultBuilder()
            .node(new NodeVerifiedAuthenticator(info))
            .milestone(new MilestoneDidAuthenticate(info))
            .build();
    }
    
    private ReactToResult handleSecondaryAuthentication(AuthenticationContext context, Input input) {
        // 处理次认证逻辑（TOTP）
        if (input instanceof LoginTOTPInput) {
            LoginTOTPInput totpInput = (LoginTOTPInput) input;
            
            AuthenticatorInfo info = getAuthenticatorService().verifyTOTP(
                context.getUserId(),
                totpInput.getTOTPCode()
            );
            
            if (info == null) {
                return new ReactToResultBuilder()
                    .error(new AuthenticationException("Invalid TOTP code"))
                    .build();
            }
            
            return new ReactToResultBuilder()
                .node(new NodeVerifiedAuthenticator(info))
                .milestone(new MilestoneDidAuthenticate(info))
                .build();
        }
        
        throw new IllegalArgumentException("Unsupported input type");
    }
    
    private ReactToResult handleCreateSession(AuthenticationContext context) {
        // 创建会话
        Session session = getSessionService().createSession(
            context.getUserId(),
            SessionType.LOGIN
        );
        
        return new ReactToResultBuilder()
            .node(new NodeDoCreateSession(session))
            .milestone(new MilestoneDoCreateSession(session))
            .build();
    }
}

总结

Authgear 的 authentication flow 设计采用声明式配置、状态机驱动和事件处理机制，提供了高度可配置和可扩展的认证解决方案。在 Spring Boot 4 中实现这套架构时，我们需要关注以下关键点：

  • 使用 Spring IoC 容器管理依赖注入
  • 实现状态机模式的状态转换逻辑
  • 使用 Redis 进行状态持久化
  • 实现声明式配置的解析和执行
  • 考虑并发安全和性能优化
